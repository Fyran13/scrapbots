# Scrapbots

Build a robot from salvage, then fight raiders across an archipelago, or take on up to 11 other players online.

- `index.html` is the whole game (served by GitHub Pages).
- `server.js` is the room server for online free-for-all matches (up to 12 players per room). Run with `npm install && node server.js`.
- `render.yaml` lets Render deploy the server in one click.
